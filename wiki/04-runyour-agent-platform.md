# 04. 플랫폼 가이드: Runyour AI (Runyour Agent)

## 1. 서비스 개요 (Service Overview)
**Runyour Agent**는 흩어진 AI 경험을 하나의 플랫폼에서 통합 연결하고 실행할 수 있도록 지원하는 AI 작업 환경입니다.
* **대화, 문서 제작, 지식 활용, API 연동, AI 앱 실행**까지 단일 창에서 제공합니다.

---

## 2. 주요 기능 및 아키텍처

### 01 · Multi-Model AI Chat
* 단일 인터페이스에서 최신 LLM(Anthropic, OpenAI, Gemini, DeepSeek, Upstage 등)을 자유롭게 전환하며 사용.
* 작업 목적(문서 생성, 데이터 분석, 코딩 등)에 맞는 최적의 모델 선택.

### 02 · Knowledge Base (지식 베이스)
* 사내 문서, 프로젝트 기획서, 기술 문서, 정책 문서 등을 업로드하여 나만의 맞춤형 에이전트 지식함 구축.
* **지원 포맷:** Markdown, HWP, PDF, DOCX, PPTX, XLSX, HTML 등
* **효과:** 매번 프롬프트로 배경 맥락을 반복 설명하지 않아도 일관되고 정확한 결과물 도출.

### 03 · API Router (단일 키 통합 관리)
* 복잡한 모델별 개별 연동 없이, **하나의 API Key**로 다양한 모델을 사내 서비스 및 외부 앱에 연동.
* 실시간 호출량, 응답시간, 토큰 처리량 모니터링 및 사용량 기반 비용 관리.

### 04 · AI App (PC 로컬 실행 에이전트)
* 단순 채팅을 넘어 로컬 PC 환경에서 직접 파일을 읽고, 수정하고, 결과물을 생성하는 실행형 도구.
* `자료 조사 ➔ 분석 ➔ 문서 작성/코딩`의 다단계 워크플로우를 자동화.

---

## 3. 통합 거버넌스 및 관리
* 조직 및 그룹별 사용량 모니터링
* 모델별 비용 현황 및 크레딧 통합 관리
* 보안 및 권한 제어를 통한 안전한 AI 운영

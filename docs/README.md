# 프로젝트 문서 길잡이

현재 작업은 아래 문서와 저장소 루트의 [PLAN.md](../PLAN.md)를 기준으로 합니다. 과거 기록과 현재 설명을 한 문서에 계속 이어 붙이지 않습니다.

| 필요할 때 | 문서 |
|---|---|
| 다음 작업을 시작하거나 팀원과 분담할 때 | [개발 작업 가이드](development-workflow.md) |
| 코드 구조와 데이터 흐름을 볼 때 | [구현 안내](implementation.md) |
| 문제·사진·정답을 추가하거나 수정할 때 | [문제 작성](mission-authoring.md) · [현장 검수](field-missions.md) |
| 그림 지도·탐색 범위·GPS 동작을 볼 때 | [지도 안내](map.md) |
| 로컬 실행·자동 검사·공개 배포의 차이를 볼 때 | [실행과 배포](deployment.md) |

## 자료 보관 구분

- 현재 문서는 기존 파일을 직접 갱신하며, 단순 이전 버전이나 완료된 정리 보고서를 별도 복사해 두지 않습니다. 필요한 근거는 관련 최신 문서에 통합합니다.
- `private/`: 공유 대상에서 제외한 로컬 자료.
- `deliveries/`: 발표·전달 자료. 외부 공유 여부는 파일별로 확인합니다.

공유 문서는 구현·실행·검증에 필요한 내용만 포함합니다. 로그와 임시 산출물, 원본 첨부 및 인증 설정은 공유 대상에서 제외합니다.

새 작업 계획은 루트 `PLAN.md` 하나만 갱신합니다.

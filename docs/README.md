## 자료 보관 구분

- `archive/`: 당시 기록을 보존하는 이력. 현재 명령·구조로 그대로 적용하지 않습니다.
- `private/preparation/`: 이전 기획·조사 등 로컬 준비 자료.
- `private/openclaw/`: 이전 OpenClaw 준비·설명 자료.
- `deliveries/`: 발표·전달 자료. 외부 공유 여부는 파일별로 확인합니다.
- `hackathons/`, `models/`, 테스트 관련 기존 폴더: 별도 조사·준비 기록이며 현재 앱 소스가 아닙니다.

폴더를 `docs` 아래에 보관한다는 이유만으로 전체를 Git에 올리지 않습니다. 현재 작업 문서만 공유하고 개인 자료·인증 정보·원격 테스트 기록의 기존 제외 범위를 유지합니다. 로그는 루트 `logs/`, 실험 산출물은 `work/`, 스마트폰 첨부 원본은 `.codex-remote-attachments/`로 구분합니다.

중복 계획이던 `docs/PLAN.md`는 보관 이력으로 옮겼습니다. 새 작업 계획은 루트 PLAN 하나만 갱신합니다.

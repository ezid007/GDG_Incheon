# Quiz 플로우 계획

### Quiz 플로우: 모든 미션 용어를 퀴즈로 변경

1. **퀴즈 부분 사진 페이지**:
    - 사용자에게 첫 번째 힌트(부분 사진)를 표시합니다.
    - 사용자 옵션:
      - **힌트 버튼**: 사용자에게 추가적인 힌트(부분 사진)를 제공합니다.
      - **도착 버튼**: 사용자가 도착 버튼을 눌렀을 때, 페이지는 GPS 좌표를 확인하고 다음 단계로 이동합니다.

2. **퀴즈 화면**:
    - 4지선다형 퀴즈가 표시됩니다.

3. **정답 확인 및 설명 표시**:
    - 사용자가 정답을 선택하면, 맞혔는지 여부와 함께 해당 장소 설명 및 이미지를 제공합니다.

이 플로우는 사용자 참여를 높이고 학습과 재미를 동시에 제공하는 경험을 목표로 합니다. 모든 콘텐츠와 상호작용이 사용자 중심으로 설계됩니다.
## 현재 MVP 반영 상태 · 2026-09-12

적용한 게임 흐름은 **한 장소에 두 단계의 퀴즈**다. 1차는 넓은 그림 지도와 부분 사진 힌트로 장소를 찾고, 2차는 도착 후 현장의 4지선다에 답한다. 전체 정답 사진은 2차 정답을 맞힌 뒤에만 공개한다.

현재 일반 도착은 사용자가 ‘장소를 찾았어요 → 2차 퀴즈’를 누르는 방식이다. 위 초안의 GPS 도착 판정·자동 잠금은 아직 적용하지 않았다. ‘내 위치 확인’은 사용자가 요청할 때 지도에 위치와 오차를 표시하는 탐색 보조다. 발표용 시연 도착 버튼은 별도 모드·기록으로 2차에 진입한다.

인화문 4지선다 1개를 반영했고 다른 실제 문제는 자료 검수 후 추가한다. 세부 작업 상태는 저장소 루트의 [PLAN.md](../../../PLAN.md), 구현은 [implementation.md](implementation.md), 지도는 [map.md](map.md), 문제 근거는 [field-missions.md](field-missions.md)에서 관리한다.

## 단일 지도·문제 목록 · unified-v1

차이나타운·동화마을 탭을 없애고 하나의 지도에서 문제 1·문제 2 순서로 선택한다. 현재 검수된 실제 문제는 인화문 1개다. 보존한 가상 예시는 실제 문제 수와 지도 목록에 포함하지 않는다. 다음 문제가 추가되면 정답 확인 후 다음 문제의 장소 찾기 지도로 이어진다. 문제별·일반/시연별 진행을 분리하며 기존 출제 문구·사진·정답은 유지한다.

# 제작 역할과 확인 범위

확인일: 2026-09-13

| 역할 | 확인된 작업 |
|---|---|
| 사용자 | 작품 방향·사진 역할·피노키오 정답·원격 작업·공유와 배포 범위 결정 |
| 현장 출제 팀원 | 인화문·동화마을 사진과 문제·정답 자료 전달 |
| Codex | 앱 구현·문제 연결·상태와 지도 처리·검사·문서 정비 |
| 초기 OpenClaw 시도 | 제한된 문구 작업을 시도했으나 채택한 결과 파일 없음 |

사용자 지시에 따라 현재 프로젝트 작업에는 OpenClaw를 사용하지 않습니다. 팀원이 전달한 과거 자료의 작성 표기는 원문에 보존하며, 그것을 현재 제작 도구를 사용한 사실로 바꾸어 기록하지 않습니다.

## 확인을 구분하는 원칙

코드·자동 검사 결과, 브라우저에서 확인한 화면, 실제 현장 관찰을 구분합니다. 시연 도착 버튼을 눌렀다고 실제 방문이나 GPS 인증을 했다고 기록하지 않습니다. 모델 호출 성공 표시만으로 결과물을 완성했다고 판단하지 않습니다.

현장 GPS 오차와 동화마을 벽화 전체 근거 사진은 추가 확인 대상입니다. 팀원별 발표·현장 테스트 기여는 실제 수행한 내용을 확인한 뒤 기록합니다. 인증값·세션 원본·개인 환경은 공유 문서에 쓰지 않습니다.

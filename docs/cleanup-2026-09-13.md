# 프로젝트 정리 내역

확인일: 2026-09-13. 기존 게임의 콘텐츠와 동작을 보존하면서 해커톤 제작 코드를 정비했습니다.

## 무엇이 달라졌나

| 이전 | 정리 후 | 효과 |
|---|---|---|
| HTML·CSS·JavaScript가 큰 템플릿 2개에 섞임 | `src/pages`, `src/styles`, `src/scripts`로 게임·지도별 분리 | 수정할 파일을 바로 찾고 충돌 범위를 줄임 |
| 한 줄에 여러 동작, 큰 `render()` | 일정한 들여쓰기, 소개·사진·선택지·진행률·피드백·완료별 함수 | 동작을 읽고 수정하기 쉬움 |
| 두 빌더에 템플릿 조립이 따로 존재 | `build-page.mjs`의 공통 조립·슬롯 검사 | 누락·중복된 삽입 자리로 깨진 페이지가 생기는 것 방지 |
| 현재 문서에 옛 실행 결과·계획이 누적 | 현재 설명을 다시 쓰고 이전 9개 문서는 `docs/archive/`에 보존 | 지금 따라야 할 안내가 명확함 |
| 루트와 docs에 PLAN 중복 | 루트 `PLAN.md` 하나만 현재 계획으로 사용 | 작업 상태의 기준을 하나로 유지 |
| 준비·모델·발표 자료가 docs 루트에 섞임 | 준비 자료 `docs/private/preparation`, OpenClaw 자료 `docs/private/openclaw`, 발표 PDF `docs/deliveries` | 개발 문서와 개인 자료 구분, 기존 공개 제외 유지 |
| 쓰지 않는 힌트 사진 2장이 배포 폴더에 남음 | `reference/unused-photos/`로 무손실 이동 | 원본을 보존하면서 배포물에서 542,131바이트 제외 |
| main 푸시가 검사와 배포를 같이 실행 | 자동 검사 `check.yml`, 수동 배포 `deploy-pages.yml` 분리 | 코드 검증과 공개 시점을 따로 결정 |
| 오래된 경로가 누적된 로컬 Git 제외 예외 | 현재 소스·검토 문서 기준으로 예외 목록 정리 | 새 소스가 빠지고 개인 자료가 섞이는 혼란 감소 |

## 현재 수정 위치

```text
apps/golmok-detective/
  src/
    pages/       game.html, map.html — 화면 구조
    styles/      game.css, map.css — 디자인
    scripts/     game.js, map.js — 화면 이벤트·렌더링
  data/          문제 JSON·스키마·지도 데이터
  public/
    assets/      실제 사용 사진·QR·예시 그림
    index.html   자동 생성 게임
    map.html     자동 생성 지도
  reference/     현재 사용하지 않는 사진 원본
  tests/         상태·데이터·지도·서버·빌드 검사
  build.mjs      게임과 지도 빌드 진입점
  build-map.mjs  지도와 카드 생성
  build-page.mjs 페이지 소스 조립
  serve.mjs      로컬 서버
  *.mjs          게임 상태·시연·위치·검증 모듈
```

실행 방법은 그대로입니다. 생성 HTML은 직접 고치지 않으며 소스 수정 후 빌드합니다. 호환성을 위해 생성 HTML의 위치와 Git 추적은 유지했습니다. 생성물 충돌이 나면 소스를 먼저 해결한 뒤 다시 빌드합니다.

`.editorconfig`와 앱의 `.prettierrc.json`은 UTF-8, 줄바꿈·들여쓰기·따옴표 방식을 맞춥니다. 이번 정렬은 Prettier 3.6.2를 임시 실행했으며 앱에 새 런타임 의존성을 추가하지 않았습니다.

## 보존한 것

- 실제 3문제와 예시 3문제, 1차/2차/정답 사진 역할, 정답·해설·지도 데이터
- 일반 플레이와 시연 진행 분리, 같은 탭에서 새로고침 복원, QR와 링크 복사
- 사용자 첨부 원본과 준비 자료. 이동한 사진·문서는 해시를 확인했으며 삭제하지 않았습니다.
- 개인 계정 저장소와 공동 작업자 설정. `.env` 값과 인증 정보는 읽거나 문서에 넣지 않았습니다.
- `.gitignore` 내용은 수정하지 않았습니다. 개인 자료 제외는 기존 로컬 `.git/info/exclude` 방식을 유지했습니다.

## 검증과 남은 사항

`node apps/golmok-detective/build.mjs` 성공. `node --test apps/golmok-detective/tests/*.test.mjs`는 기존 76개와 새 빌드 계약 9개를 포함해 **85개 모두 통과**했습니다.

브라우저에서 소개→세로 목록→지도 선택/확대→피노키오 시연→오답/힌트/정답 사진→새로고침 복원→완료와 목록 복귀를 확인했습니다. 일반 플레이에는 시연 정답이 반영되지 않습니다. 동화마을 정답 `가방`과 근거 표시점 숨김, QR 원본 로딩과 복사 성공 안내도 확인했습니다. 320·390·1280px에서 가로 넘침 없이 표시되고 브라우저 오류가 없었습니다.

사용자 요청에 따라 공개 사이트 게시를 중단하고 배포 워크플로를 비활성화했습니다. 공개 URL의 HTTP 404를 확인했습니다. 이후 푸시는 자동 검사만 수행하며 공개 배포는 다시 요청받을 때 진행합니다. README에 배포 상태 이력은 적지 않습니다.

현장 GPS 정확도와 동화마을 전체 벽화 근거 사진은 기존 추가 확인 사항입니다. 이번 작업은 서버·계정·문제 관리 백엔드를 새로 만든 작업은 아닙니다.

다음 변경은 [작업 가이드](development-workflow.md)의 순서를 따르고, 문서의 출발점은 [문서 길잡이](README.md)를 사용합니다.

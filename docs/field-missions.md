전체 사진은 힌트·탐색 지도·도착 전 안내에 쓰지 않는다. 문제 사진의 대체 설명과 힌트에도 정답 이름을 먼저 적지 않았다. 힌트는 현장에서 시선을 돌릴 부분만 안내한다. `evidence: { "x": 48.5, "y": 44.5 }`는 **정답 확인용 전체 사진**에서 현판 중심을 표시하는 백분율이며, 문제 사진의 좌표나 GPS 좌표가 아니다.

정답 데이터와 사진은 정적 웹 배포 파일에 포함된다. 화면상 공개 시점을 구분하는 체험 게임이며, 소스 확인에 대한 정답 비밀 보장을 제공하지 않는다.

## 좌표의 출처와 범위

```json
{
  "explorationRegionId": "chinatown",
  "geoCoordinates": {
    "latitude": 37.473045,
    "longitude": 126.6188592
  }
}
```

좌표는 팀원 자료의 `geo_coordinates`를 그대로 옮긴 참고 메타데이터다. 관문 위치를 현장에서 정밀 측량한 값으로 검증한 것은 아니다. 한중문화관 인근을 포함하는 **넓은 탐색 구역의 중심을 잡는 용도**로만 사용하며, 정확한 정답 핀·도착 인증·자동 정답 해제로 사용하지 않는다. 사용자에게는 구역 안에서 사진의 조각상을 직접 찾아보도록 안내한다.

## 팀원 문제 소스 통합

팀원의 정리 커밋에 따라 `missions.json`은 사용하지 않는다. `load-quiz.mjs`는 `quiz.js`의 질문·선택지·좌표를 읽고 `quiz-support.json`의 검수 정보(단서/문제/정답 사진 설명·해설·근거 좌표·검수 정답)와 결합한다. 팀원 형식의 `correctAnswerIndex`는 1부터 시작하는 보기 번호로 해석하고, 해당 보기의 글자가 검수 정답과 같은지 확인한다. 원본 세 사진과 공개 복사본이 다르거나 새 문제가 아직 검수 목록에 없으면 빌드를 중단한다. 사진 이름만으로 힌트 공개 여부를 결정하지 않는다.

### 다섯 개로 센 근거와 확인 수준

전체 사진 Photo 2에서 같은 모양의 무늬를 다음과 같이 구분했다.

1. 피노키오 어깨 옆의 진한 파란색 무늬
2. 위쪽 청록색 무늬
3. 위쪽 옅은 분홍색 무늬
4. 가운데 옅은 민트색 무늬
5. 흰색 함의 문에 있는 분홍색 무늬

대상 범위는 **흰 벽면과 흰색 함의 문을 함께 포함**한다. 갈라진 꼬리선 하나하나를 따로 세지 않고 같은 모양의 한 덩어리를1개로 센다. 옅은색 무늬를 놓치거나 함의 문을 제외하면 개수가 달라질 수 있어 질문·힌트·해설에 이 기준을 명시했다. 사진 판독은 제작 담당과 별도 이미지 검토에서 대조했으며, 근거 마커는 전체 사진의 `evidence: { "x": 74.1, "y": 48.2 }`를 사용한다.

이는 **사용자가 보낸 사진을 판독한 결과**다. 현장에서 사용자에게 다시 세어 확인받았다고 기록하지 않는다. 선택적으로 요청한 현장 확인 답변은 아직 도착하지 않았으며, 이후 현장 관찰이나 더 선명한 자료가 오면 범위·개수·문구를 다시 대조한다. 촬영 지점을 정밀 확인한 GPS 기록은 없고 지도는 기존 대표점 주변의 넓은 탐색 범위만 제공한다.

### 추가 버전 검증 상태

콘텐츠 버전을 `unified-pinocchio-v1`로 갱신해 이전 단일 문제 진행 상태와 구분했다. 실제 문제2개·예시3개를 합친5개 데이터의 로컬 빌드가 성공했고, 전체72개 검사 중70개 통과·기존 AdGuard HTML 헤더/HEAD 관련2개 실패를 확인했다. 이번 버전의 두 문제 연결·사진 공개 시점에 대한 브라우저 확인과 CI·공개 배포 확인은 대기 중이다. 이전 `unified-v1`의 CI72개 성공은 새 피노키오 문제의 배포 증거로 사용하지 않는다.

# 안내판 사진 기반 탐색 지도

확인일: 2026-09-12 · 적용 버전: 원본 사진 확대 뷰어 v1

## 현재 구현

`apps/golmok-detective/public/map.html`은 사용자가 현장에서 촬영해 전달한 개항장·차이나타운 관광안내판 JPEG를 포함한 단독 HTML이다. 이미지 데이터는 원본 파일의 바이트를 그대로 data URI로 넣었다. 외부 지도 API, 폰트, 이미지 서버, 위치정보 API, 모델 호출을 사용하지 않는다.

- 화면 맞춤, 단계별 확대·축소(맞춤 크기의 100–500%)와 스크롤 이동을 제공한다.
- 640px 이하에서는 처음부터 300%로 시작하고 PC에서는 맞춤 크기로 시작한다. 맞춤 버튼은 100%로 돌아간다.
- 모바일 브라우저의 기본 두 손가락 확대를 허용한다. 별도 GPS·방향·경로 계산은 없다.
- 기본 화면에서는 오른쪽 관광지 설명 목록 일부를 CSS 영역으로 덜어낸다. ‘사진 전체 보기’로 원본 전체 범위를 볼 수 있다.
- 밝기·대비는 CSS 필터만 변경한다. ‘원본 밝기로 보기’는 두 값을 100%로 되돌린다. JPEG 픽셀과 글씨를 수정하지 않는다.
- 붉은 선은 원래 안내판에 그려진 관광 코스이며 게임 추천 경로가 아니라고 표시한다.
- 원본이 기울어져 있고 작은 글씨가 흐릿하다는 한계는 남는다. 확대만으로 없는 해상도가 복원되지는 않는다.

## 정답 노출 제어

지도 이미지 위의 별도 불투명 레이어로 확인 가능한 두 패루 라벨을 가렸다. 가림 영역은 원본 1280×591을 기준으로 계산하며 확대 시 같은 비율로 함께 움직인다. ‘사진 전체 보기’에서도 가림은 유지된다.

| 대상 | 원본 기준 영역 | 상태 |
|---|---|---|
| 제1패루(중화문) 라벨 | 왼쪽 23.44%, 위 40.61%, 너비 5.94%, 높이 9.14% | 브라우저 대조에서 초기 영역 밖 글씨가 보여 범위를 넓힌 뒤 확인 |
| 제3패루(선린문) 라벨 | 왼쪽 35.08%, 위 40.61%, 너비 6%, 높이 6.1% | 브라우저 대조에서 초기 영역 밖 글씨가 보여 범위를 넓힌 뒤 확인 |
| 제2패루/인화문 및 기타 정답 단서 | 미지정 | 해당 사진에서 정확한 라벨 위치를 확정하지 못해 임의 가림하지 않음. 실제 문제에 사용하기 전 추가 대조 필요 |

원본은 HTML에 포함되므로 가림 레이어는 일반 플레이 화면에서의 노출을 줄이는 장치다. 정답을 기술적으로 비공개로 보호하는 방식이 아니다. 개발자 도구나 원본 이미지에서 답을 볼 수 있으므로 점수·위치 인증에 사용하지 않는다.

사진 힌트에서도 **정답을 직접 보여주는 현판·문 이름이 읽히는 사진은 제외**한다. 사용자가 전달한 문 전체 사진은 현판을 읽을 수 있으므로 현재 상태 그대로 힌트에 넣지 않는다. 주변 건물·길·구조를 보여주는 사진도 동일하게 사전 확인한다. 이 지도 추가만으로 기존 게임 미션이나 힌트 사진은 교체하지 않는다.

## 생성 보정본을 채택하지 않은 이유

원본을 바탕으로 생성한 PNG는 더 선명해 보였지만 다음 명칭을 바꾸었다. 길찾기 근거로 부적합하여 현재 HTML에 넣지 않았다.

| 원본 사진 | 생성 PNG의 잘못된 표기 |
|---|---|
| 한국기독교 100주년 기념탑 | 인천도호부 관아지 |
| 백범김구동상 | 배다리구두촌 |
| 대동호텔(인천 최초 상업적 호텔) | 한국기독교 100주년 기념탑 |

원본에서 읽히지 않는 지명이나 도로 연결을 새로 추정해 그리지 않는다. 생성 PNG는 채택하지 않았으며 후속 이미지 생성이나 OpenClaw 호출도 하지 않았다.

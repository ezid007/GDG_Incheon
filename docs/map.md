# 그림 지도와 대략 위치 탐색

확인일: 2026-09-12 · 지도 설정: exploration-v1 / field-and-preview · 미션 데이터: field-v2 · 브라우저 표준 Geolocation API · 새 패키지/SDK 없음

## 현재 동작

차이나타운·송월동 동화마을의 실제 도로를 SVG 그림 지도로 단순화했다. 정답 핀 대신 **넓은 원과 크롭된 사진 단서로 장소를 찾는 1차 퀴즈**다. 장소를 찾은 뒤 스스로 확인 버튼을 눌러 **현장을 관찰하는 4지선다 2차 퀴즈**로 이동한다.

| 구역 | 현재 상태 | 탐색 범위 |
|---|---|---|
| A · 차이나타운 남쪽 골목 (`chinatown`) | 팀원이 작성한 인화문 현판 미션 1개 연결 | 공식 한중문화관 대표점을 중심으로 반경135m |
| B · 동화마을 골목 (`songwol`) | 실제 문제 준비 중. 현장 퀴즈 버튼과 사진 단서 없음 | 공식 동화마을 대표점을 중심으로 반경110m |

A 구역에서는 금빛 조각상의 크롭 사진과 장소를 찾는 설명만 보여준다. **현판 전체 사진과 정답 문구는 지도에 넣지 않으며, 전체 사진은 2차 퀴즈에 정답을 고른 뒤에만 화면에 공개한다.** 지도에 정답 핀이나 포토존 전체 목록도 표시하지 않는다.

- `map.html` 하나에 지도·구역·사진 단서·위치 처리 코드를 모두 내장한다. 플레이 중 외부 지도 타일/API를 호출하지 않는다.
- 지도 확대/축소/전체 보기, 손가락·스크롤 이동, A/B 구역 선택을 제공한다.
- 북쪽이 위다. 도로 좌표와 사용자 위치에 같은 투영식을 사용한다.
- **내 위치 확인**을 눌렀을 때 한 번만 위치를 요청한다. 자동 추적·백그라운드 수집·위치 저장·서버 전송 없음.
- 정상 위치는 파란 점과 예상 오차 타원으로 표시한다. 1분이 지나면 점을 숨기고 재확인을 안내한다.
- 지도 범위 밖, 100m 초과 오차, 오래된 값, 잘못된 좌표는 점을 표시하지 않는다. 지도 가장자리로 임의 보정하지 않는다.
- HTTPS·사용자 위치 권한이 필요하다. 거부, 위치 조회 불가, 15초 조회 제한, 권한창을 포함한 20초 UI 대기 제한과 재시도를 제공한다.
- 위치 확인은 탐색을 돕는 선택 기능이다. GPS 인증을 강제하지 않으며 위치로 정답을 열거나 실제 도착을 인증하지 않는다. 도로의 현재 출입 가능 여부와 안전한 이동은 현장 안내를 따른다.

## 현장 진행과 발표 시연

현장 진행과 발표 시연은 서로 다른 링크와 기록을 사용한다.

| 사용 목적 | 지도 버튼 / 주소 | 동작 |
|---|---|---|
| 실제 현장 진행 | **장소를 찾았어요 → 2차 퀴즈**, `./?play=field&region=chinatown` | 도착을 스스로 확인하고 연결된 현장 문제를 바로 연다. GPS 성공 여부와 무관하다. |
| 발표 시연 | **시연: 도착했어요 → 2차 퀴즈**, `./?demo=arrival&region=chinatown` | 실제 방문 없이 도착을 가정한다는 시연 안내와 함께 현장 문제를 연다. |
| 준비 중인 B 구역 시연 | `./?demo=arrival&region=songwol` | 이 구역의 실제 문제 대신 가상 예시 문제를 보여주며 예시임을 안내한다. |

현장 링크는 연결된 실제 문제가 있는 구역에서만 표시한다. B 구역의 `?play=field&region=songwol`에 직접 들어와도 가상 문제를 현장 문제처럼 보여주지 않고 준비 중 화면을 표시한다. 구역을 전환하면 현장·시연 링크도 선택한 구역에 맞게 바뀐다. 두 버튼 모두 가짜 GPS 점이나 도착 인증 기록을 만들지 않는다.

`demo-session.mjs`가 현장·시연·일반 진행의 문제 목록과 저장 키를 분리한다. 현장 진행은 `golmok-detective:field:v1:<region>`, 시연 진행은 `golmok-detective:demo-arrival:v1:<region>`, 일반 진행은 `golmok-detective:v1`을 사용한다. 팀원이 실제 문제를 전달하면 `sceneKind: "field"`와 `explorationRegionId`로 연결하며, 해당 구역의 준비 상태와 사진 단서는 빌드 시 미션에서 결정한다.

## 지리 데이터와 출처

| 항목 | 근거 |
|---|---|
| 도로·공원·철도 | [OpenStreetMap 공식 map API](https://api.openstreetmap.org/api/0.6/map?bbox=126.615,37.472,126.627,37.481), 2026-09-12 조회 |
| 동화마을 구역 대표점 | [인천투어 송월동 동화마을](https://itour.incheon.go.kr/ssst/ssst/detail.do?cotId=ITD22012113593866643)의 mapx/mapy. 정확한 입구·문제 좌표가 아님 |
| A 구역 중심 | [인천투어 한중문화관](https://itour.incheon.go.kr/ssst/ssst/detail.do?cotId=ITD21121514191939746)의 대표점: 위도37.4735836355535, 경도126.618776323953 |
| 인화문 장소 확인 | [인천투어 패루 안내](https://itour.incheon.go.kr/ssst/ssst/detail.do?cotId=ITD21122913231279219): 제2패루 인화문은 한중문화관 입구의 금색 용 문양 패루. 정확한 문 좌표를 제공하는 자료는 아님 |
| 지도 저작권 | [© OpenStreetMap contributors](https://www.openstreetmap.org/copyright), 지리 데이터 [ODbL](https://opendatacommons.org/licenses/odbl/1-0/) |
| 위치 요청 조건·옵션 | [MDN getCurrentPosition](https://developer.mozilla.org/en-US/docs/Web/API/Geolocation/getCurrentPosition) |
| 위치 정확도 | [MDN accuracy](https://developer.mozilla.org/en-US/docs/Web/API/GeolocationCoordinates/accuracy) |
| 위치의 보장 범위 | [W3C Geolocation](https://www.w3.org/TR/geolocation/) |

화면에는 OSM 저작권과 인천투어 링크를 표시한다. 지리 데이터 원본 범위는 서126.615 / 남37.472 / 동126.627 / 북37.481, 화면은 그 안의 **서126.615 / 남37.472 / 동126.624 / 북37.4805**이다. 인화문 주변을 포함하도록 화면의 남쪽 범위를 확장했다. bbox 밖으로 이어지는 도로는 SVG clipPath로 자른다. `foot=no`, 일반 `access=no/private` 도로는 표시 대상에서 제외하되 `foot=yes` 예외를 고려한다. 이 필터가 현장의 통행 가능 여부를 보증하지는 않는다.

A 구역 중심은 인화문 정답 핀이 아닌 한중문화관의 공식 대표점이다. 팀 미션에는 위도37.473045, 경도126.6188592가 함께 전달되었고 문화관 인근임을 대조했지만, 문의 정확한 좌표라는 사실은 확인되지 않았다. 이 값은 GPS 도착 인증에 사용하지 않는다. B 구역 중심은 위도37.4782594659769, 경도126.619971883104이며 정확한 입구나 아직 없는 문제의 위치를 뜻하지 않는다.

## 파일과 설정

- `apps/golmok-detective/map.template.html`: 화면·구역 선택·사진 단서·위치 조회·현장/시연 링크.
- `build-map.mjs`: 지리 데이터를 SVG로 만들고 위치 코드와 구역에 연결된 첫 현장 미션의 크롭 사진을 HTML에 내장. 정답 전체 사진은 지도에 넣지 않음.
- `demo-session.mjs`: 구역별 현장/시연 문제 선택, 준비 중 처리, 진행 기록 분리.
- `location.mjs`: 위경도→그림 좌표, 유효성·오차·시간 검사.
- `data/map-geography.json`: OSM 데이터와 공식 대표점, 출처·라이선스.
- `data/exploration-map.json`: bounds, region id/letter/name/위경도/radiusMeters/description/source. `ready`는 빌드 시 연결된 실제 미션의 존재로 다시 결정.
- `data/quiz.js`, `data/quiz-support.json`, `load-quiz.mjs`: 팀원 문제 원본과 검수 정보에서 `sceneKind`, `explorationRegionId`, 크롭 `image` 등을 구성한다. 지도에는 2차 `quizImage`·`answerImage`를 포함하지 않는다.
- `public/map.html`: 배포 산출물. 직접 수정하지 않고 원본을 빌드한다.

```sh
node apps/golmok-detective/build.mjs
node --test apps/golmok-detective/tests/*.test.mjs
```

위치 처리 예시:

```js
const result = assessLocation(position, map.bounds, map.width, map.height);
if (result.status === 'ready') {
  // x/y에 점, radiusX/radiusY에 오차 타원을 표시한다.
}
```

A 135m·B 110m 구역 반경과 100m 위치 오차 한계는 MVP 초기 설정이다. 실제 스마트폰과 현장 동선으로 조정한다. 위치 접근 자체에 모델 API·지도 API 키를 쓰지 않는다. 단순 정적 웹이므로 정답의 화면 공개 시점을 제어하는 것이며, 배포 파일 자체를 열람할 수 없도록 숨기는 구조는 아니다.

## 검증과 남은 확인

- 순수 위치 함수 13개: 모서리·중심·범위 밖·정확도 경계·잘못된 값·만료·불변성 통과.
- 지도 UI 14개: 실제 산출물 스크립트를 Node VM의 테스트 DOM/시계/위치 fixture로 실행. 성공·거부·미지원·시간 초과·큰 오차·범위 밖·1분 만료·늦은 응답 무시·구역 링크 일치에 더해, 실제 미션 구역에서만 사진/현장 링크가 표시되는지와 지도에 정답 전체 사진을 내장하지 않는지 검사한다.
- 브라우저: 기존 320px·390px·PC에서 구역 전환·확대·전체 보기와 페이지 가로 넘침 없음을 확인했다. 현장 링크·사진 단서를 포함한 최종 화면과 공개 주소도 확인했다. 실제 휴대전화 핀치·현장 GPS 점의 정확도는 미검증.
- 테스트 좌표는 검사 안에서만 사용하며 서비스에는 가짜 GPS 위치를 넣지 않는다. 발표용 버튼도 위치 데이터와 별개다.
- 로컬 전체 검사에는 기존 AdGuard HTTP 변조 때문에 헤더/HEAD 검사 2건이 계속 실패한다. 변경된 순수 상태·지도·미션 검사는 별도 통과했고 CI에서는 전체68개 검사가 통과했다.

## 이전 사진 지도

사용자 안내판 사진은 원본 자료로 보존했다. 기울어진 관광안내도는 축척·도로 위치가 왜곡되어 GPS 좌표를 바로 얹지 않는다. 이전 사진 확대 HTML은 로컬 기록에 보존하고 현재 공개 지도는 실제 도로 SVG로 교체했다. 생성 이미지의 잘못된 지명 문제를 피하기 위해 이번에는 새 이미지 생성 없이 실제 좌표와 코드로 그렸다.

- 2026-09-12: 팀원이 작성한 인화문 4지선다를 A 구역에 연결. 지도와 크롭 사진으로 장소를 찾는 1차, 자가 확인 후 현장 문제를 여는 2차로 정리하고 일반 현장 링크와 발표 시연을 분리. A를 공식 한중문화관 주변135m, B를 동화마을 대기 구역110m로 설정하고 남쪽 지도 범위를 확장. 전체 정답 사진은 지도에서 제외하고 2차 정답 후에만 화면에 공개.

## 최종 배포 확인 · field-v2

2026-09-12 코드 커밋 `4deb9db`의 [GitHub Actions](https://github.com/ezid007/GDG_Incheon/actions/runs/34672204009)에서 68개 검사·빌드·배포가 성공했다. 로컬 응답 필터 실패2건은 CI에서 재현되지 않았다. 공개 HTTPS의 시작 버튼→1차 지도→일반 도착→2차 가림 사진·4지선다→정답 원본 사진·해설→완료를 브라우저에서 확인했다. 시연 주소는 별도 진행 0/1로 열리고 시연 안내가 표시된다. 브라우저 주소와 링크가 GitHub Pages 저장소 경로 아래에서 정상 연결된다. 현장 GPS 오차는 실제 휴대전화 확인이 남아 있다.

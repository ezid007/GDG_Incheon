# 동화마을 골목탐정

사진 속 단서를 찾아 장소의 특징을 발견하는 짧은 모바일 관찰 게임입니다. Agent Field Trip 2026: Incheon에서 만드는 작품으로, 현장에서 관찰한 내용과 게임의 질문·정답 근거를 연결하는 것이 목표입니다.

**[골목탐정 플레이하기](https://ezid007.github.io/GDG_Incheon/)** — GitHub Pages에서 제공하며 개발 노트북이 꺼져 있어도 접속할 수 있습니다.

현재 게임은 가상 예시 그림 3미션입니다. 실제 현장 미션은 아직 반영하지 않았습니다. 별도의 [현장 탐색 지도](https://ezid007.github.io/GDG_Incheon/map.html)는 참가자가 보내준 안내판 사진을 확대해 보여줍니다.

팀원은 `main`에 게임 코드를 푸시하면 테스트·빌드 후 자동 배포할 수 있습니다. 수동 실행은 GitHub Actions → **Deploy Golmok Detective → Run workflow → main**입니다. Pages 설정 변경은 개인 저장소 소유자가 담당합니다.

팀원이 추가한 차이나타운 관문 사진·미션 초안은 `raw/missions/`와 [미션 문서](wiki/mission-chinatown-gate.md)에 보존되어 있습니다. 해당 자료는 다음 콘텐츠 반영 대상이며 현재 예시 게임과 구분합니다.

## 어떻게 플레이하나요?

1. 시작 버튼을 누릅니다.
2. 그림과 질문을 보고 답을 고릅니다. 필요하면 힌트를 볼 수 있습니다.
3. 답을 확인합니다. 틀렸다면 다른 답을 선택하고, 맞혔다면 근거를 읽습니다.
4. 다음 미션으로 이동합니다. 모든 미션을 풀면 완료 화면을 확인합니다.

회원가입이나 앱 설치 없이 브라우저에서 이용하는 형태입니다. 같은 탭에서 새로고침하면 진행 상태를 복원하며, 완료 후 다시 시작할 수 있습니다. 미션은 1개만 있어도 끝까지 플레이할 수 있도록 구성했습니다.

## 로컬 실행

검증 환경은 Node.js 22/24입니다. 별도 패키지 설치는 필요하지 않습니다. 저장소 루트에서 실행합니다.

```sh
node apps/golmok-detective/build.mjs
node apps/golmok-detective/serve.mjs
```

브라우저에서 [http://127.0.0.1:4179](http://127.0.0.1:4179)를 엽니다. 다른 포트가 필요하면 다음처럼 실행합니다.

```sh
node apps/golmok-detective/serve.mjs --port 4180
```

`127.0.0.1` 주소는 서버를 실행한 컴퓨터에서만 열립니다. 휴대전화에서는 위의 공개 HTTPS 주소를 사용하세요. 주소 재발급과 수정 반영 방법은 [공개 운영 안내](docs/golmok-detective/deployment.md)에 있습니다.

## 작업과 검증

미션 원본은 `apps/golmok-detective/data/missions.json`입니다. 내용이나 게임 코드를 변경한 뒤 빌드하고, 아래 검사를 실행합니다.

```sh
node --test apps/golmok-detective/tests/*.test.mjs
```

2026-09-12 지도 공개 경로를 포함한 **21개 검사가 GitHub Actions에서 모두 통과**했습니다. 로컬 실행에서 발생했던 AdGuard의 HTML 헤더·HEAD 응답 변경 실패 2건도 기록을 유지합니다. 자세한 범위와 남은 검증은 [구현·협업 안내](docs/golmok-detective/implementation.md)에 기록합니다.

## 동료가 참여할 부분

- **현장 관찰:** 직접 찍은 사진, 장소 이름, 관찰한 특징을 정리합니다.
- **문제 작성:** 사진에서 확인할 수 있는 질문·선택지·힌트·정답 근거를 만듭니다.
- **제작과 확인:** 미션 데이터를 반영하고 휴대전화에서 실제 흐름을 검사합니다.
- **발표 준비:** 관찰이 기능에 연결된 이유, 사람별 역할과 Agent 활용, 작동 화면을 준비합니다.

브라우저에서 3미션 완주, 오답 재시도, 힌트, 그림 확대, 새로고침 복원, 재시작과 주소 복사를 확인했습니다. 320·390·768·1280px 화면 폭에서 가로 넘침이 없고, 공개 HTTPS의 GET·HEAD 응답도 정상입니다. 실제 현장 휴대전화의 모바일 데이터망 확인은 팀원이 이어서 진행합니다.

진행 계획은 [PLAN.md](PLAN.md), 파일 구조와 데이터 작성법은 [구현·협업 안내](docs/golmok-detective/implementation.md), 제작 과정은 [Agent 작업 기록](docs/golmok-detective/agent-work.md)을 참고하세요. 이 노트북의 기존 개인 문서·실행 로그·인증 자료는 새 커밋에서 제외합니다. 팀원이 이미 공유한 `wiki/`, `raw/`, 저장소 지침은 보존합니다.

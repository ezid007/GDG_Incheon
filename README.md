# 차이나타운 골목탐정

**그림 지도와 사진 힌트로 장소를 찾고, 그 자리에서 4지선다 문제를 푸는 모바일 골목 탐험 게임**입니다. Agent Field Trip 2026: Incheon에서 수집한 사진과 현장 관찰을 게임의 단서·정답 근거로 연결합니다.

**[골목탐정 플레이하기](https://ezid007.github.io/GDG_Incheon/)** — GitHub Pages에서 제공하므로 개발 노트북이 꺼져 있어도 접속할 수 있습니다.

2026-09-12 현재 작업 버전은 `unified-pinocchio-v1`입니다. **인화문 현판과 피노키오 주변 무늬를 묻는 실제 문제 2개**를 하나의 지도와 문제 목록으로 연결했습니다. 지역 탭 없이 문제 1·문제 2 순서로 선택하며 기존 가상 예시 3개는 실제 목록에 넣지 않습니다. 새 피노키오 문제는 제공 사진을 판독해 구성했으며 사용자의 현장 확인을 받은 것으로 표시하지 않습니다. 로컬 빌드·검사를 마쳤고 이번 버전의 브라우저·CI·공개 배포 확인은 대기 중입니다.

## 어떻게 플레이하나요?

**한 문제마다 한 장소를 찾고 관찰하는 2단계 미션**입니다. 문제 1의 두 단계를 마치면 문제 2의 장소 찾기로 이동합니다.

1. **문제 선택:** 목록에서 문제 1 황금빛 관문 또는 문제 2 동화 속 작은 무대를 선택합니다.
2. **1차 · 장소 찾기:** [그림 지도](https://ezid007.github.io/GDG_Incheon/map.html?quiz=inhwamun-plaque)의 넓은 탐색 범위와 부분 사진으로 선택한 문제의 장소를 찾습니다.
3. **2차 · 현장 퀴즈:** ‘장소를 찾았어요 → 2차 퀴즈’를 누르고 문제 사진과 실제 장소를 살펴본 뒤 4개 선택지 중 하나를 고릅니다. 관문 문제는 현판을 가린 사진, 피노키오 문제는 주변 전체가 보이지 않는 근접 사진을 사용합니다.
4. **정답 확인:** 틀리면 다시 선택하고, 맞히면 전체 확인 사진·정답 근거·해설을 확인합니다.
5. **다음 장소 또는 목록:** 문제 1을 마치면 [문제 2 장소 찾기](https://ezid007.github.io/GDG_Incheon/map.html?quiz=pinocchio-clouds)로 이동하고, 마지막 문제에서는 목록으로 돌아갑니다. 문제별 진행과 새로고침 복원을 지원합니다. 새 문제의 공개 주소 반영은 배포 확인 후 확정합니다.

전체 정답 사진은 장소 찾기나 힌트에 사용하지 않고 **정답을 맞힌 뒤** 공개합니다. 회원가입이나 앱 설치는 필요하지 않습니다.

## 지도와 시연

지도는 실제 도로 좌표를 그림처럼 단순화하고 정답 위치 대신 **선택한 문제의 넓은 탐색 범위**를 보여줍니다. 문제를 바꾸면 같은 지도에서 범위·부분 사진·도착 버튼의 연결 대상이 함께 바뀝니다. 지역 이름을 먼저 선택할 필요가 없습니다.

휴대전화에서 ‘내 위치 확인’을 누르면 위치 접근 허용 후 현재 위치와 오차 범위를 한 번 표시합니다. 위치는 저장하거나 서버로 보내지 않습니다. 지도 밖·큰 오차·오래된 위치에는 잘못된 점을 표시하지 않으며 실제 현장 휴대전화의 정확도는 추가 확인이 필요합니다.

**GPS로 도착을 인증하거나 문제를 잠그지 않습니다.** 플레이어가 장소를 찾았다고 판단하면 직접 2차 퀴즈로 넘어갑니다.

발표에서는 지도 아래의 **‘시연: 도착했어요 → 2차 퀴즈’** 또는 [문제 1 도착 시연](https://ezid007.github.io/GDG_Incheon/?demo=arrival&quiz=inhwamun-plaque)을 이용합니다. 현장에 가지 않고 선택한 문제의 2차 퀴즈를 체험할 수 있으며, 화면에 시연 표시를 유지합니다. 진행 기록은 문제별·현장 플레이/시연별로 분리하고 실제 문제 목록에 가상 예시를 섞지 않습니다.

## 로컬 실행

검증 환경은 Node.js 22/24입니다. 별도 패키지 설치 없이 저장소 루트에서 실행합니다.

```sh
node apps/golmok-detective/build.mjs
node apps/golmok-detective/serve.mjs
```

브라우저에서 [http://127.0.0.1:4179](http://127.0.0.1:4179)를 엽니다. 다른 포트는 다음처럼 지정합니다.

```sh
node apps/golmok-detective/serve.mjs --port 4180
```

`127.0.0.1` 주소는 서버를 실행한 컴퓨터에서만 열립니다. 휴대전화에서는 공개 HTTPS 주소를 사용합니다. 수정 반영과 운영 조건은 [공개 운영 안내](docs/deployment.md)에 있습니다.

## 문제 작성과 배포

팀원 문제 원본은 `apps/golmok-detective/data/quiz.js`입니다. `load-quiz.mjs`가 질문·보기·사진 경로를 읽고 `data/quiz-support.json`의 검수 정보·예시와 결합합니다. 사진, 질문, 선택지 4개, 정답, 근거, 넓은 탐색 구역을 [미션 작성 양식](docs/mission-authoring.md)에 맞춰 전달합니다. 실제 문제는 4지선다, 보존한 가상 예시는 3지선다입니다. 코드나 자료를 수정하면 게임과 지도를 다시 빌드합니다.

이전 팀원 문제 초안 `python/quiz_class_sample.py`와 `raw/missions/`·`wiki/` 자료는 [커밋 096c7fc](https://github.com/ezid007/GDG_Incheon/tree/096c7fc)의 기록으로 남아 있습니다. 게임은 검수해 복사한 `public/assets/` 사진을 사용합니다. 인화문 미션은 사진의 실제 현판과 선택지를 대조해 반영했으며 기존 초안의 다른 관문 이름·역사 설명은 가져오지 않았습니다. 새 피노키오 문제는 사용자가 전달한 사진 3장을 부분 단서·2차 문제·정답 확인용으로 나눠 사용합니다. [현장 미션 검수 기록](docs/field-missions.md)에 사진 기반 정답 판단과 공개 시점, 현장 확인 여부를 기록합니다. 기존 인화문 출제 내용은 유지합니다.

팀원은 `main`에 게임 코드를 푸시하면 테스트·빌드 후 자동 배포할 수 있습니다. 수동 실행은 GitHub Actions → **Deploy Golmok Detective → Run workflow → main**입니다. Pages 설정 변경은 개인 저장소 소유자가 담당합니다.

## 검증 상태

```sh
node --test apps/golmok-detective/tests/*.test.mjs
```

`unified-pinocchio-v1`은 실제 문제 2개·보존 예시 3개를 합친 5개 데이터의 로컬 빌드에 성공했습니다. **로컬 전체 72개 중 70개 통과·기존 AdGuard 응답 변조 관련 2개 실패**입니다. 원본과 공개 사진의 일치는 로더에서 검사합니다. 이번 버전의 두 문제 브라우저 흐름·CI·공개 배포는 대기 중이며 실제 휴대전화의 현장 위치 정확도와 피노키오 무늬 개수의 사용자 현장 확인은 미확인입니다.

이전 `unified-v1` 코드 `f12fe15`는 **GitHub Actions 72개 검사·빌드·배포가 모두 성공**했습니다. [이전 단일 문제 배포 기록](https://github.com/ezid007/GDG_Incheon/actions/runs/34673092862) 당시 공개 Chrome에서 문제 1의 지도→도착→가림 사진·4지선다→정답 원본→완료→문제 목록, 시연0/1 분리와 로컬320·1280px/공개390px의 가로 넘침 없음을 확인했습니다. 이 결과는 새 피노키오 문제를 포함한 버전의 배포 검증이 아닙니다.

이전 `field-v2`에서는 로컬 상태·지도·미션·세션 검사 59개가 통과했고, 서버 포함 68개 중 66개 통과·기존 AdGuard의 HTML 헤더 변경/HEAD 파싱 관련 2개 실패였습니다. GitHub Actions에서는 68개 검사·빌드·배포가 모두 성공했습니다. [이전 배포 검사 기록](https://github.com/ezid007/GDG_Incheon/actions/runs/34672204009) 당시 실제 미션의 정답 사진·완료·새로고침, 시연 기록 분리, 320·390·1280px 화면을 확인했습니다. 초기 예시 버전의 CI 21개 통과 기록도 보존합니다. 이 결과를 이번 버전의 검증 완료로 사용하지 않으며, 최신 상태는 [구현·협업 안내](docs/implementation.md)에 기록합니다.

## 동료가 참여할 부분

- **현장 관찰:** 직접 찍은 사진, 장소 이름, 관찰한 특징을 정리합니다.
- **문제 작성:** 현장에서 확인할 질문·선택지·정답 근거를 작성합니다. 장소를 찾는 사진과 정답 확인 사진을 구분합니다.
- **제작과 확인:** 미션 데이터를 반영하고 휴대전화에서 1차 탐색부터 2차 퀴즈·완료까지 검사합니다.
- **발표 준비:** 현장 관찰이 기능에 연결된 이유, 사람별 역할과 Agent 활용, 실제 플레이와 시연 화면을 준비합니다.

진행 계획은 [PLAN.md](PLAN.md), 구현 내용은 [구현·협업 안내](docs/implementation.md), 제작 과정은 [Agent 작업 기록](docs/agent-work.md)을 참고하세요. 관련 없는 개인 문서·실행 로그·인증 자료는 공유하지 않으며 팀원이 정리한 현재 폴더 구조를 따르고 기존 자료의 Git 기록과 검수한 게임 자산을 유지합니다.
